# T08生产接入与验证断点

日期：2026-11-07。状态：进行中，未签核。正式历史基线仍为T07冻结快照；当前工作源码包含T08候选。

## 本轮已完成

- 接入版本化可变长度属性DMA、APB格式选择0x0F0及命令快照。格式0保留未压缩回退，格式1使用候选编码。
- 新增ENABLE_COMPRESSED_ATTRIBUTES，默认0。启用时，协方差及选择标志和原Gaussian一起穿过属性issue、分叉、共享均值变换、lane分发及弹性流水，进入生产协方差旋转链。
- 当前通过携带辅助字段经过原世界协方差流水保持原有延迟/顺序，随后选择预计算结果。原算术硬件仍保留，不能宣称已消除其面积或全部动态计算成本。
- DMA模块6144条记录、9类控制/错误检查通过，包含4KiB拆分、格式/地址错误、RID/RRESP、早/晚RLAST、背压及错误后正常请求。
- 真实子集矩阵80次通过：五场景、各512 Gaussian、宽128、四模式×两AXI×未压缩/压缩。RGB DMA与T07参考逐字节一致；内部状态按既定终止T合同检查；实际预计算路径计数对应。
- 五场景未压缩/压缩非空连续两帧共10次运行通过；五场景交替raw escape/预计算记录共5次混合格式运行通过。共95次不同运行，初始10次冒烟属于80矩阵，不重复计数。
- 默认兼容回归84次编译/83次执行通过，能力开关0/1的生产lint通过。

## 性能与范围

512记录负载中属性读量由4608拍降至3987–4091拍，下降约11.22%–13.48%。
同一候选硬件中格式1相对格式0：ideal平均周期增加约0.042%，最差增加约0.189%；limited平均周期减少约1.035%，范围约0.317%–2.041%。
这证明实际属性字节减少，尚不证明完整模型/原生分辨率吞吐改善。固定144字节槽位的模型驻留大小未减少。

## 原生分辨率历史诊断

已审计上轮冻结T07版结果：Bonsai、Counter、Room均在20亿周期未完成而超时。
Train完成1,012,803,782周期，Truck完成1,003,006,820周期，均仅PROTOCOL_PASS_REFERENCE_PENDING。
假定200MHz分别约0.197/0.199 FPS，频率未经签核，远未达到30FPS。
两张RGB DMA图像已查看，可辨认主体，但背景/边缘存在拉长、条纹或模糊现象；原因尚未用独立参考/GT确定，不能直接归因于模型或宣布画质通过。

## 中断与失败记录

完整模型压缩对照程序已构建，但后续输入编码中断。状态检查时没有存活编码/仿真进程，WSL为新启动实例；Bonsai/Counter仅有attribute.partial，各240,864,624字节，无完整模型result.json。
中断具体原因未确定。已将过期RUNNING修正为INTERRUPTED_DURING_INPUT_ENCODING，保留partial文件；不能报告后台仍在运行。

历史模块回归曾因新增辅助输入未在四个旧通配符连接测试台中声明而编译失败；补齐零值连接后完成回归，旧失败日志保留。
连续帧测试台派生脚本曾拒绝不唯一插入锚点和与单帧不同的拍数表达式，修正派生规则后10次连续帧通过；该失败发生在生成/构建前，不计作RTL错误或成功仿真。

## 恢复顺序及剩余工作

1. 核验并保留中断的编码产物，恢复五完整模型同版本未压缩/压缩对照。入口scripts/run_t08_extended.py full；不能在partial存在时直接反复启动，脚本会保护性拒绝覆盖。
2. 补齐生产顶层格式错误/错误后恢复、continuation格式一致性等新增边界验证。DMA模块错误测试不能替代完整系统恢复。
3. 完整模型图像/独立参考、性能与资源成本闭环；继续原生分辨率和共享DDR/缓存写回瓶颈处理。正式GT、PPA和30FPS仍未通过，不转T09最终拟合。
4. 生产配置与源码签核前冻结，完整必要证据缺失时T08保持未签核。

证据均位于experiments/t08_20261031：integration_20261107/matrix_report.json、extended_20261107/repeat_report.json、mixed_20261107/report.json、dma_20261107/report.json、regressions_20261107/report.json、recovery_20261107/native_audit.json及status_audit.json。
