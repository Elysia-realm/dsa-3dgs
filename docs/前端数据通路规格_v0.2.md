# 3DGS前端数据通路规格 v0.2

- 日期：2026-08-04
- 目标：面向动态可重构ASIC的可复制projection lane；把训练场景中的原始
  quaternion/scale逐步转换为tile任务及光栅alpha描述符。
- 状态：第二轮工艺无关SystemVerilog RTL已通过Icarus自检查回归。
- 路线更新：ADR-007后，本文tile坐标统一作为当前Gaussian内部8×8 block坐标；
  不再规划Gaussian–tile KV/bin和逐tile排序主路径。

## 1. 本轮冻结的输入与中间格式

| 数据 | 格式 | 真实负载依据 |
|---|---|---|
| normalized quaternion | signed Q1.20，22位 | 绝对值最大约0.999998 |
| scale | unsigned Q4.20，24位 | 最大约3.02017 |
| world/camera covariance | signed Q24.16，41位 | 绝对值最大约8.72054 |
| screen covariance | Q24.8，32位 | 极端约1.13e10，溢出保守回退 |
| internal conic | signed Q4.40，44位 | 正则化后系数最大约3.33332 |
| internal Cholesky | Q4.20，24位 | 因子绝对值最大约1.82572 |
| raster Cholesky | Q3.12 | 直接匹配alpha核 |
| factor/coordinate shift | signed 6位 | 实测约-14..-1和0..8 |

## 2. 数值数据流

1. normalized quaternion生成旋转矩阵`R`。
2. `M=R*diag(scale)`，世界协方差`Sigma_world=M*M^T`。
3. 相机旋转得到`Sigma_camera=V*Sigma_world*V^T`。
4. perspective Jacobian得到带0.3正则化的二维协方差`Sigma_2D`。
5. 计算`C=inverse(Sigma_2D)`，但不直接量化三个conic系数。
6. 分解`C=L*L^T`并对`L`做块浮点编码，从表示层保持二次型非负。
7. bbox采用Gershgorin最大特征值上界、向上取整sqrt和opacity感知支持半径。
8. 每个tile任务携带均值、深度、二维协方差、bbox、opacity、Cholesky因子、
   coordinate/factor shift和数值错误标志。

## 3. 保守性合同

- covariance、除法、变换或编码溢出必须置位错误，不能静默错误剔除。
- bbox的eigenvalue估计使用上界；sqrt和opacity半径均向上量化。
- opacity半径最大限制为3 sigma，异常时仍可使用3 sigma或全屏安全回退。
- 奇异或非正定二维协方差事务必须完成并置位错误，不能阻塞流水线。
- fixed与dynamic模式共享完全相同的算术和描述符；动态只决定epoch内启用的lane数。
