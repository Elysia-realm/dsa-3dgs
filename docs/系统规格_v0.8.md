## 2. 两级提前终止结构

### 2.1 像素级mask

- 每个8×8块维护64位像素终止mask。
- blend提交接口只发送本次新终止的像素位；更新操作为按位OR，不允许清位。
- 表项包含完整block tag和epoch；直接映射容量碰撞只会替换旧项，不会继承别的块mask。
- 新epoch通过tag失配得到空mask，不批量清除数据阵列。
- 同周期同block/epoch查询更新采用写穿透。
- 首次由非全1变为全1时只产生一个`block_terminated_pulse`。

### 2.2 块级终止表

- 像素mask的首次全终止脉冲写入bank化块终止表。
- 光栅入口在昂贵属性读取和alpha发射前查询粗表。
- 当前`raster_pair_shell`已经把外部blend mask更新口、像素mask和块终止表串联。
- 64项自动化测试已覆盖mask单调性、首次脉冲、epoch隔离、容量碰撞、同周期写穿透和层级集成。

## 3. 定点alpha真实负载扫描

### 3.1 方法

- 场景/相机：garden/184、train/150、bonsai/291。
- 每个视角选取左上、中心、右下三个64×64 ROI，共9个ROI。
- 每ROI从精确投影Gaussian/像素对中固定随机种子、无放回抽样100,000项，共900,000个样本。
- FP64/FP32公式与多个候选Q格式比较，统计alpha绝对误差以及阈值分类的假剪枝/假blend比例。
- 原始结果：`experiments/fixed_alpha_sweep.json`。

### 3.2 关键发现

首版统一格式（delta 5整数+10小数、conic 8整数+12小数、256项exp LUT、alpha 12小数）被真实负载否决：平均alpha绝对误差约0.2175，阈值分类不一致率约33.72%。样本中的绝对像素偏移最大约148,085，而二次型系数可小至接近零；统一Q格式无法同时覆盖巨大偏移和极小系数。

把delta整数位简单扩大到18位仍不够。即使conic小数位扩大到24位，扫描中平均绝对误差仍约0.0437、阈值分类不一致率约8.52%，不能作为图像质量可接受的RTL格式。

### 3.3 数值架构修订

alpha RTL暂不按首版统一Q格式实现。下一候选必须先在软件模型中验证以下至少一种表示：

1. 投影阶段把局部坐标和conic按块/高斯共同尺度归一化，再计算二次型；
2. 使用共享指数的块浮点格式保存`dx/dy`与conic；
3. 对超大屏幕高斯使用独立慢路径或范围分段格式；
4. 直接量化预变换后的二次型参数，避免两个大偏移平方与极小系数相乘。

已额外验证每高斯共享二进制尺度：按`dx'=dx/2^s`、`C'=C*2^(2s)`保持数学二次型不变。它把阈值分类不一致率由33.72%降到约7.77%，但仍明显不可接受；主要剩余风险是独立量化三个conic系数后可能破坏半正定性。下一候选应优先量化Cholesky/主轴因子，从表示层保证二次型非负。

选择标准不是单点alpha误差最小，而是先满足阈值分类稳定，再以整幅图像PSNR/SSIM/LPIPS和PPA共同裁决。

## 9. 阶段10增量：保半正定alpha与blend闭环

### 9.1 alpha首个RTL候选

- 不再直接存储/量化`conic00/conic01/conic11`，投影阶段分解为2×2 Cholesky因子。
- 光栅使用`(l00*dx+l10*dy)^2 + (l11*dy)^2`，量化后仍天然非负。
- 坐标和因子分别使用每高斯二进制指数，避免超大投影高斯要求宽整数乘法器。
- 首个面积均衡候选：delta Q5.10、Cholesky Q3.12、轴中间量Q4.10、opacity/alpha Q1.12、256项exp LUT、T Q0.16。
- 900,000个真实样本结果：阈值分类不一致率约0.186%，P99 alpha绝对误差约0.01044，平均绝对误差约0.000485。
- 512项LUT保留为画质/PPA备选，不在首版无条件扩大。

### 9.2 已新增RTL

- `alpha_block_float_core`：四级ready/valid弹性alpha流水和256项本地LUT。
- `blend_fixed_core`：Q1.12 RGB/alpha与Q0.16透射率的前向blend。
- `image_state_store`：64×64 tile局部4096像素状态，无容量别名，epoch逻辑清空。
- `blend_state_commit`：保守单事务读改写基线，保证同像素严格有序。
- `raster_pair_shell`：终止过滤、alpha、图像状态/blend、像素终止mask和粗终止表串联。
- `apb_regfile`、`sram_1r1w_wrapper`和`gs_accel_top`首版接口。
