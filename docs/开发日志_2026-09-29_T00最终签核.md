# 2026-09-29 T00 最终签核日志

## 用户确认

用户确认 ASIC 只验收标准单元逻辑综合及 STA、面积、活动功耗，不要求布局布线；使用 ICsprout55 与 FreePDK45 比较，SRAM 用 CACTI、片外主存用 Ramulator/LPDDR4，覆盖 SS/TT/FF。正式硬线为 200 MHz、30 FPS、4 mm²、300 KB、1 W；目标为 300 MHz、2.7 mm²、0.8 W，1 GHz 为 GCC 对标冲刺值。正式负载为本地 13 场景完整 30k 模型、每场至少 5 个 `camera.json` 视角；画质相对软件 3DGS 的 PSNR/SSIM/LPIPS 容差已冻结。参数压缩须严格减少参数字节并继续满足帧率和画质合同。

## 口径收敛

- 将“200 或 300 MHz”明确为 200 MHz 最低通过、300 MHz 目标；1 GHz 不作为最低毕业验收线。
- 将面积与功耗分别分成 4 mm²/1 W 硬线和 2.7 mm²/0.8 W 目标线。300 KB 放宽必须另行批准并修订合同。
- FreePDK 解释为 FreePDK45；具体发布版本和标准单元库变体由 T01 在首次正式映射前锁定。
- 两套工艺分别出报告；跨 45/55 nm 以及与 GCC 28 nm 比较时保留工艺差异，不能直接用原始面积/功耗差宣称架构收益。
- 无真实封装/SoC 预算时，采用时钟周期 5% uncertainty、10% input delay、10% output delay；真实预算可通过版本修订替换。
- 参数压缩未设固定压缩率，但必须使参数总字节严格下降，并满足 30 FPS 和逐视角画质门槛。
