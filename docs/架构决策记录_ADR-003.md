# ADR-003：提前终止优先于复杂帧内动态互连

- 状态：接受，等待全帧/多ROI和ASIC PPA继续复核
- 日期：2026-08-04

## 背景

候选块模型在39个真实视角中显示，最佳固定模式全部为光栅优先，帧内动态配置相对最佳固定模式平均只具有约1.23%的候选周期潜力。该模型尚未逐像素执行alpha和透射率提前终止。

## 新证据

对garden、train和bonsai代表视角的完整高斯集合投影，并在中心64×64 ROI执行精确逐像素轨迹：

- 提前终止后的alpha计算量分别为禁用终止时的38.47%、4.67%和9.98%；
- 活跃块访问分别为28.69%、2.70%和7.64%；
- 三个ROI的所有像素最终均达到`T < 1e-4`。

这些数字只描述中心ROI，不能外推为全帧加速比，但已证明包围盒候选块不是足够精确的光栅负载代理。

## 决策

在ASIC实现顺序中，将逐像素T状态、块终止掩码和早期任务/属性读取跳过置于复杂帧内动态资源互连之前。光栅优先R1继续作为主候选，shadow/active和epoch能力继续保留，但逐窗口在线重构暂不进入最小可行RTL。

## 理由

1. 提前终止直接减少alpha、blend、属性读取和结果队列压力，作用面大于当前约1.23%的动态候选收益。
2. 块终止状态可用局部SRAM、比较和控制实现，架构风险低于多路动态互连。
3. 终止会改变不同深度窗口的负载形态；在终止前决定动态模式可能产生错误结论。
4. 保留epoch控制使方案仍可在后续PPA证据充分时升级。

## 后果

- 下一版scoreboard必须同时管理同块提交次序和块终止状态。
- 终止查询应发生在SH/颜色属性读取和alpha发射之前。
- 需要增加bank冲突、掩码容量、查询端口和写回延迟的面积/时序评估。
- 动态R1是否保留为论文主方案，改由“终止后真实任务流 + ASIC PPA”共同决定。
