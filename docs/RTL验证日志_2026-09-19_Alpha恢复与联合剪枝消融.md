# 2026-09-19：恢复 Alpha 优化验收与联合剪枝消融

## 恢复点与本轮范围

恢复 2026-09-17 因额度中断的工作：低 alpha 像素状态事务跳过已实现，原 15 负载
360 次 DMA 的源码证据仍匹配。该轮候选 120/120 相对共享投影基线提速，平均少
28.100% 周期；减少 45,496 次状态读与 72,688 次状态写。此为上一轮已完成的
优化成果，本轮不把它重复计为新增 RTL 收益。

本轮没有修改 RTL 或 DMA testbench，完成了中断的结构检查，并新增可复现的
`shape_alpha_skip` 五路联合消融入口、重叠工作守恒审计、自动两帧探测及回归。
深度分组 → Gaussian 有序发射/退休 → Gaussian 内部 8×8 block 遍历、动态
G/P/R/E 保持原合同。`ENABLE_ALPHA_ZERO_SKIP` 与
`ENABLE_SHAPE_BLOCK_REJECT` 均保持默认关闭。

## 五路对照与边际收益

新运行 200 次 DMA：Train/Garden/Kitchen 三个 n32 场景，以及 Train n128 d8
和 d64 两个负载；每个负载覆盖 G/P/R/E × ideal/limited AXI × 五变体：完全
旁路、共享基线、单独形状剪枝、单独低 alpha 跳过、联合方案。每个负载全部
epoch 生效后的 RGB/T 图像一致。联合方案相对单独低 alpha 方案，原始 frame-slot
哈希也 40/40 相同。120 个重叠基线配置的全部 perf 字段、原始/语义帧哈希与
2026-09-17 当前源码报告完全相同。

| 联合方案相对单独低 alpha | 提速 | 持平 | 退化 | 平均额外周期节省 |
| --- | ---: | ---: | ---: | ---: |
| 三场景 n32 | 12/24 | 12/24 | 0/24 | 0.995% |
| Train n128 d8 | 0/8 | 8/8 | 0/8 | 0.000% |
| Train n128 d64 | 4/8 | 4/8 | 0/8 | 0.947% |
| 合计 | 16/40 | 24/40 | 0/40 | 0.787% |

合计平均每配置额外节省 17.625 周期，少执行 2,504 次 alpha 任务，额外状态读
和状态写减少均为 **0**。这些像素本来就会在低 alpha 退休处跳过；块级判定把
跳过位置前移，进一步省去 alpha 计算，但没有再省一次 blend/状态事务。
审计显式检查：

- 共享提交数 − 单独形状提交数 = 单独 alpha 跳过数 − 联合 alpha 跳过数；
- 单独形状提交数 − 联合提交数 = 联合 alpha 跳过数；
- 单独 alpha 与联合方案的有效提交数一致。

所有 40 个联合配置均快于共享基线，但只有 32/40 快于完全旁路；剩余 8 个
均为 n128 d8。以上平均值为逐配置百分比的算术平均。这个五负载样本与上一轮
十五负载样本不同，不应直接比较两个总体平均值来推断版本退化或提升。

## ASIC 结构与自动模式

本机 Verilator 5.050 使用 `--json-only` 导出展开 AST（旧的 `--xml-only`
选项不可用）。按顶层可达实例加权统计：默认/alpha/联合分别为
369/369/370 个有符号乘法 AST 节点，均为 37 个无符号乘法节点；共享 PE
实例均为 1，形状判定器分别为 0/0/1。由此确认 alpha 跳过不新增乘法算子，
联合方案增加形状判定的一个算子。**AST 节点包含函数体和常数运算，绝不是
映射后物理乘法器数、标准单元面积或功耗。**

Train n32 自动两帧续跑：联合方案最终 RGB/T 与共享基线一致，epoch=2；
累计拒绝 14 个块、跳过 1,058 个低 alpha 像素。第二帧选择 R 模式，周期为
1,256，共享基线 1,921，单独 alpha 上轮同源码证据为 1,289。此探测证明
联合候选跨 epoch 功能正确，尚不能签核全场景自动策略最优性。

本轮 Python **163/163 PASS**；新增重叠计数损坏注入测试能拒绝错误报告，
当前源码/结构及自动帧文件哈希检查通过。联合顶层 Verilator lint 成功，保留
非致命告警。RTL/testbench 未修改，因此继承上一轮 79 项 Icarus 自检与综合
入口的同源码证据；本轮没有重复宣称新跑了该全套回归。

## 计划调整

1. 首个 ASIC PPA 比较优先采用 **共享基线 vs alpha-only**；联合形状方案作为
   独立消融保留。本轮只有约 0.787% 的额外周期收益，不能未测映射成本就默认
   增加形状判定硬件，也不能把两种单独优化的节省相加。
2. 下一轮 RTL 性能优化优先评估共享 G 插入排序的**稳定二分定位候选**。
   当前 `stable_group_sorter_shared_compare` 逐项线性搜索，继续复用既有 G
   比较器、保留插入搬移与有序发射，验证相等完整 key 的稳定性、容量边界、
   仲裁背压和完整场景周期。该候选尚未实现，不预先宣布性能通过。
3. 保留 n128 d8 作为前端受限反例：G/ideal 下，低 alpha 使状态写从
   1,421 次降至 578 次，但周期仅 4,721→4,720。共享基线 collect=387、
   drain=4,326；旁路为 270/2,997。sort/projection busy 计数有重叠，不能
   相加成阶段占比；数据支持优先调查前端共享服务与依赖等待。
4. ASIC 验收仍需导师/学校确定工艺库、SRAM 宏、PVT、频率及可用综合/STA/功耗
   工具。当前工程 `asic/` 未提供 `.lib/.lef`，PATH 未找到 Yosys/OpenSTA/
   OpenROAD/DC/Genus；`wsl.exe --list --quiet` 也未正常返回可用环境。
   在这些输入就绪前，继续 RTL 优化，但 Gate 1/2 仍 PARTIAL，PPA 不签核。
