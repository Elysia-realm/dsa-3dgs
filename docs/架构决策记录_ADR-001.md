# ADR-001：从R0转向配对光栅资源R1

- 状态：接受为下一阶段候选，等待RTL与真实场景复核
- 日期：2026-08-03
- 决策范围：动态可重构资源池的光栅化边界

## 背景

R0在投影、排序和alpha之间分配弹性额度，但blend保持固定。四类合成负载中，离线最优调度均退化为单一静态模式，且增加alpha通道不能提高最终提交速率。

## 决策

停止把R0作为最终主架构候选。后续R1将alpha入口、blend提交口和结果队列容量组成配对光栅通道，并与投影、排序资源在统一暂定面积额度下比较。

## 理由

1. alpha结果必须经过blend才能提交到Image Buffer，二者是连续吞吐链。
2. R0实验证明固定blend会截断alpha扩展收益。
3. R1在密集及强遮挡合成负载中分别减少约23.1%和23.8%的模型周期，说明配对边界更合理。
4. 异质定向测试中，R1能根据切换开销选择或取消“投影优先→光栅优先”切换，调度语义有效。

## 限制

- R1资源额度尚未由RTL面积标定，不能称为等面积硬件比较。
- 普通四类合成场景未出现动态切换，尚不能证明帧内动态调度必要。
- R1密集负载收益可能被真实SRAM端口、bank冲突和互连成本削弱。

## 后果

- 下一步RTL优先实现配对光栅通道的最小数据通路、握手、队列和scoreboard提交接口。
- 投影与排序只需先做可综合面积/时序标定模块，不立即实现完整共享互连。
- 真实场景统计若仍由单一模式主导，则把设计收敛为场景级/子图级可配置架构。

## 复核条件

满足任一条件时重新评估本决策：

1. 综合显示配对光栅通道的面积或关键路径显著高于暂定权重。
2. 真实场景中blend并非主要瓶颈。
3. SRAM端口或同块依赖使增加blend通道无法提高提交吞吐。
4. 跨场景最佳模式稳定一致，动态配置没有统计必要性。
