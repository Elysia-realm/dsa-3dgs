# RTL验证日志：排序阶段交换后旁路与扩容审计

日期：2026-09-13；接续低预算回退与批间转发轮。

## 1. 实现与范围

新增候选参数`ENABLE_PHASE_FORWARDING`，frame/system对应
`PARALLEL_SORT_PHASE_FORWARDING=1`；`USE_PARALLEL_GROUP_SORT=0`生产默认不变。
预算1流式插入、首项锁存预算和同阶段不相交batch转发保持。

上轮禁止跨奇偶阶段直接读旧数组。本轮只在最后batch响应且尚未完成排序、有合法下一
比较对时，允许下一阶段请求同拍发出。新增交换后source-address选择：凡下一比较操作数
落在本拍交换对内，选择该对交换前的另一位置，形成写回后的depth/GID/sequence值。
同时对下一batch本地比较采样使用同一交换后视图；旧响应仍写旧地址。仲裁失败后写回并
切REQ，下一拍读新数组重试，完整请求保持检查通过。单项及无合法比较对的空阶段不发请求。

这不是把上轮的“跨阶段禁止”静默删除：独立开关保留旧算法，明确实现数据依赖旁路后再
做A/B验证。没有新增key比较PE，但新增地址比较/选择mux，关键路径成本尚无STA证据。

固定深度分组 → Gaussian有序发射/退休 → Gaussian内部8×8 block遍历不变；动态
G/P/R/E、epoch及lane mask不变。仍是1个共享G/P PE+最多3个专用key比较器混合候选，
不是全共享多PE阵列，R未接入；camera/RGB IO、全场景批边界、GT及PPA目标不降级。

## 2. 模块工作计数

新增八个32-bit累加输出：共享比较、本地比较、奇偶网络交换、奇偶阶段、输出group、
串行fallback group、阶段转发授权及阶段转发失败。reset清零，溢出按32-bit环绕，clear_overflow
仅清既有错误位，不清工作计数。这里交换只计网络交换，不计串行插入shift，阶段不计插入搜索。
测试平台监控实际请求/响应/输出事件，对全部计数逐项核验。

当前这些是模块接口诊断输出；frame显式留空，尚未接APB，综合可能裁掉计数寄存器。
因此不能声称生产软件已能读取总排序工作，更不能把诊断寄存器位数作为实际面积结果。
下一步仍需插入shift计数、系统连线、计数清零/快照协议及APB测试。

## 4. 真实DMA与最终回归

三场景n32 × 四模式 × ideal/limited AXI × 四配置，共96项：bypass、默认shared_projection、
上轮adaptive（阶段旁路关）、本轮phase（开）。未复测prepass-only和最早奇偶版本的完整
n32矩阵，其历史报告保留；prepass-only仅本轮73项回归内的小DMA负载再次运行。

96项全部图像hash等价；72项旧配置跨轮输出、工作量、周期逐项不变。新phase相对串行
18/24提速、6/24持平、0退化，G/P/R均6/6提速，E均相同。相对上轮adaptive同样18项
再省4–8周期、6项不变，24项合计节省106周期；这是多个不同case合计，不是某一整帧收益。
phase开/关的G比较、P与main MAC工作量相同，state读写/commit不变，排除漏工作造成收益。

候选相对完整旁路平均+2.414649%、最大+6.181534%；上轮为+2.637230%/+6.181534%，
默认串行仍+3.166617%/+6.376110%。平均继续改善、最大不变，整体性能NOT PASS。
微负载默认/旁路/prepass-only/phase为621/602/610/621，均68commit、68state读写。

Python133/133通过（新增工作量一致及模块计数范围合同两项）；Icarus最终73项自检+
1次综合入口编译通过，包括candidate continuation、epoch、异常排空及后续恢复。
默认/候选Verilator lint通过，未出现
Error/LATCH/MULTIDRIVEN/UNOPTFLAT；展开验证仍1个共享PE、1个候选sorter、0个独立
串行sorter，主XYZ本地实例4→0范围不变。非致命告警保留，Icarus `SYNTHESIS`绕过SVA，
没有形式、门级、STA、面积/功耗签核。

最终证据：`sorter_ablation_final/report.json`、`dma_matrix/report.json`、
`dma_matrix/baseline_comparison_report.json`、`dma_matrix/elaboration_report.json`；
Python、Icarus和默认/候选lint日志已留存在同一证据目录。模块及DMA报告保存RTL/TB SHA256，

## 5. 修订下一轮规划

1. 当前不应继续只消除空拍：容量/预算扩大后奇偶网络比较工作量成为边界。评估预算2回退、
   通用单调/近单调快速路径或按容量与预算划分的算法选择；不能按场景名单绕开失败。
   所有选择需同组存储、完整三级键稳定性、tie到达顺序及动态epoch合同验证。
2. 补serial shift、接生产工作计数/APB快照，分清真实总工作与共享grant；不把模块诊断当系统闭环。
3. 单PE collect仍每Gaussian三MAC，下轮逐阶段计数后比较多slice/streaming Z资源折中；
   候选相对串行不退化不能代替相对完整旁路吞吐验收。
4. 资源能力未稳定，不先调自动建议器；全共享/R、形状联合剪枝、camera/RGB、GT/PPA仍待完成。
