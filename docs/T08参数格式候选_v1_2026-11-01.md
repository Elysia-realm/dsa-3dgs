# T08参数格式候选v1

状态：模块验证阶段，未接入生产DMA/渲染，不是正式发布格式。当前生产配置仍为T07。
依据：`T08验收与入口诊断计划_2026-10-31.md`、完整五模型字段统计和生产协方差RTL。

## 1. 单一候选与取舍

每个GID保留144字节固定槽位，避免增加一次偏移表DMA。槽内有效记录为3、4、6、8或9个
128-bit拍；未来DMA先取头拍，再按头字段读取剩余有效拍，必须计入分段请求成本。
模型固定槽位总大小不下降，预计收益是实际DMA参数字节减少；不得把有效负载之和冒称模型文件缩小。
未压缩现有格式作为命令级回退；候选格式内部另有raw escape。命令级选择、快照及接口版本入口尚未接通。

本候选先保持已有定点语义：SH重要度采用剩余高阶系数是否全部为零，确定最低保留阶数。
非零误差预算的全方向SH尾项界仅作分析，未选择有损阈值。16-bit SH只裁去冗余符号位，
超出范围使用18-bit；不作截断/饱和。世界协方差预计算保持生产RTL的全部舍入、窄化和溢出逻辑。
世界协方差实际为41-bit、20位小数，不能根据历史`q16`端口名或早期规格误用16位小数。

本地文献核对：GCC第8页§4.4–4.6支持有限预取、状态掩码和按需执行，但没有提供本项目
SH/协方差压缩格式；其Cmode子视图/binning不纳入本候选。GSCore正文未给出可直接移植的
该类编码格式。这里的位宽、零高阶选择和固定槽方案来自本项目实际字段统计，不能称为论文原方案。

## 2. 位布局（最低有效位先传）

头16位：`[7:0]=0xC8`，`[9:8]=1`，`[10]=raw`，`[12:11]=SH degree`，
`[13]=SH宽度选择（0:16、1:18）`，`[15:14]=0`。

raw记录：头必须为`0x3DC8`，后接原1118-bit属性向量，共1134有效位，9拍。
记录内的raw escape与命令级未压缩格式不同，不能对旧格式无条件跳过16位。

预计算记录：

| 位置 | 内容 |
|---|---|
| [15:0] | 头 |
| [96:16] | 原81-bit world mean向量，保留原z低位/y/x布局 |
| [109:97] | 原13-bit opacity |
| [253:110] | 六个signed24 Q*.20协方差，低位依次xx/xy/xz/yy/yz/zz |
| [254起] | 每通道保留K=(degree+1)²个SH系数，R后G后B；每项signed16或signed18 Q*.12 |

有效拍数=`ceil((254+3*K*coeff_width)/128)`。预计算值有溢出、任何协方差不适合signed24、
或压缩记录不比9拍短时，当前主机编码器选择raw escape。尾部未使用位由主机置零，解码器忽略
尾部padding，不声称检测其非零值；魔数、版本、保留头位、raw canonical头及拍数错误明确拒绝。
单个解码错误返回error和零输出字段；后续集成必须禁止错误记录参与计算并正确完成AXI排空/恢复。

## 3. 计算链接口

解码器输出原1118-bit向量、246-bit世界协方差、precomputed和degree，保持ready/valid。
压缩记录原向量中的quaternion/scale字段为零，**必须通过precomputed标志走协方差旁路**，
绝不能把它作为旧原始属性直接送入当前投影lane，否则会造成错误几何。
协方差输出高位到低位为xx/xy/xz/yy/yz/zz，各符号扩展至41位；SH缺省高阶补零。
valid复位，payload不复位，消费者只能在valid握手时使用payload。

后续必须将该标志/协方差/degree与GID、sequence、epoch一起穿过属性缓冲、投影/SH分叉、
lane分配和退休；raw路径继续在线计算。不能只让解码模块PASS而绕开生产链验收。

## 4. 已测与未测

- 世界协方差2048向量：1536组归一化输入与512组任意位模式；独立恒等式、溢出、标签和背压通过。
- 编解码3590向量：五场景各512真实记录、1024合成极值/阶数记录、6非法格式；背压和待响应复位通过。
- 五完整模型有效字节估计减少12.515%–14.709%，见`parameter_analysis_20261101/report.json`。
  当前没有压缩DMA字节或整帧收益；固定144字节槽不节省模型驻留空间。
- 尚未完成：DMA头拍/可变长度/4KiB/错误恢复、命令选择、生产协方差旁路、完整图像对拍、
  四模式/双AXI与连续帧、局部成本与总预算、GT及最终D08门槛。
