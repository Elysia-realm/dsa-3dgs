# ADR-004：采用终止感知的低频模式选择

- 状态：接受，等待更广泛真实轨迹和ASIC PPA复核
- 日期：2026-08-04

## 背景

终止前的39视角候选块模型中，最佳固定模式全部为光栅优先，帧内动态候选收益平均约1.23%。随后中心ROI精确轨迹证明提前终止可大量削减深层光栅工作，但中心区域可能存在采样偏差。

## 新证据

在garden、train和bonsai代表视角上使用3×3空间网格，共生成27个64×64精确ROI轨迹：

- alpha保留比例为4.67%至84.98%，中位数16.15%；
- 终止后最佳暂定固定模式为均衡19个、光栅优先7个、排序优先1个；
- 当前暂定窗口模型中，动态相对各ROI最佳固定模式的周期比几何平均约0.880；
- 9个ROI不发生切换。

该结果使用暂定面积额度、简化窗口模型和ROI采样，不能解释为12%的ASIC净加速。

## 决策

将主候选从“固定光栅优先R1 + 可选低频配置”修订为“终止感知的低频模式选择”。保留均衡、光栅优先和排序优先配置，运行时只在安全的长epoch边界依据终止后负载统计选择模式。固定光栅优先继续作为重要消融基线。复杂逐窗口动态互连仍暂缓。

## 理由

1. 提前终止会直接改变阶段瓶颈，终止前模式结论不能可靠沿用。
2. 多位置结果证明空间差异真实存在，单中心ROI不足以支撑全帧决策。
3. 现有shadow/active与epoch骨架已经支持低频模式切换，无需立即增加复杂在线网络。
4. 在ASIC PPA未知时，低频方案保留研究价值，同时控制面积、频率和验证风险。

## 后果

- 调度统计必须在终止过滤之后采集活跃块、alpha和blend计数。
- 模式选择LUT应以长epoch统计为输入，并设置滞回/最小驻留时间。
- 论文必须同时报告固定光栅优先、最佳固定模式、低频动态模式和理想离线动态上界。
- 最终是否实现更细粒度切换，由更广泛真实轨迹和目标库PPA共同决定。
