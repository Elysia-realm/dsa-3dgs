# 工作区目录说明

后续开发统一入口：[毕业设计剩余任务执行清单](毕业设计剩余任务执行清单_2026-09-20.md)。
按 T00–T13 指定任务执行，每项包含交付物、验收条件、依赖和停止优化条件。

- `docs/`：系统规格、进度记录和研究决策。
- `model/reference/`：功能黄金模型。
- `model/cycle/`：周期与数据移动模型。
- `rtl/`：SystemVerilog设计。
- `verification/`：测试向量、testbench和结果检查。
- `experiments/`：实验配置与输出，不存放公开上传内容。
- `scripts/`：本地辅助工具。
- `参考文献/`：本地论文资料。
- `tmp/`：可删除的本地中间文件。

所有课题资料默认视为保密内容，只在本地工作区处理。
