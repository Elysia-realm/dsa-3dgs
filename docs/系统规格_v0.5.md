# 3DGS动态可重构ASIC加速系统规格 v0.5

- 状态：完成13场景、39视角真实候选块负载分析，进入ASIC PPA校准
- 日期：2026-08-04
- 目标平台：ASIC
- 继承：`系统规格_v0.4.md`的R1配对光栅结构、共享任务图和epoch协议
- 保密要求：真实模型和统计仅保存在`D:\3DGS`本地

## 1. 真实数据集

本地数据集包含13个训练完成的3DGS场景：bicycle、bonsai、counter、drjohnson、flowers、garden、kitchen、playroom、room、stump、train、treehill和truck。

- 每个场景均包含iteration 7000和iteration 30000的点云、`cameras.json`及训练配置。
- 本版统一使用iteration 30000作为最终模型。
- 最终模型合计39,781,233个高斯，单场景约102万至613万。
- 单场景相机数125至311。
- 原始分辨率约1264×832至5187×3361。
- iteration 30000相对iteration 7000的高斯数量增长约1.08倍至1.84倍。

## 2. 导入格式

13个最终PLY格式一致：二进制小端、每高斯62个FP32字段。

- 位置：`x/y/z`。
- 法向量占位：`nx/ny/nz`。
- SH：3个DC和45个高阶系数，共每通道16项。
- opacity：训练logit，导入时执行sigmoid。
- scale：3个对数尺度，导入时执行exp。
- rotation：4元数，导入时归一化。

导入器使用内存映射和分批读取，避免把多百万高斯重复加载到内存。相机JSON中的position和camera-to-world rotation转换为world-to-camera矩阵，并支持保持视场角的分辨率缩放。

## 3. 第一轮真实负载分析方法

为了在可接受时间内覆盖全部模型，本版采用候选块级向量化分析：

1. 对完整高斯集合计算真实相机深度。
2. 使用完整3D协方差、视角旋转和投影Jacobian估计2D协方差。
3. 按opacity阈值计算屏幕包围盒和8×8候选块数。
4. 按深度排序，并以4096个深度可见高斯为一个负载观察窗口。
5. 使用暂定R1服务率比较均衡、投影优先、排序优先和光栅优先配置。
6. 对动态模式显式计入12周期切换开销。

统一将每个视角最长边缩放到1920像素。每个场景选取首、中、末三个相机，共39个视角。

## 4. 分析边界

本轮结果不是精确渲染周期，原因包括：

- 统计包围盒候选块，尚未逐像素计算alpha。
- 未加入逐像素提前终止和形状精确裁剪。
- 未模拟SRAM bank冲突、读写端口、同块真实依赖和DRAM带宽。
- R1面积额度及服务率尚未由ASIC综合校准。
- 每个场景仅抽取三个相机，不代表全相机平均。

因此本结果只用于判断负载分布和动态配置的潜在必要性。

## 5. 真实负载结果

39个视角中：

- 最佳固定模式全部为`raster_priority`。
- 动态配置相对最佳固定模式的几何平均周期比为0.9877，即候选块模型周期平均减少约1.23%。
- 11个视角的潜在收益超过1%，9个超过2%。
- 5个视角完全不切换。
- 最大潜在收益约7.71%，出现在garden抽样视角。
- train三个抽样视角均全程光栅优先且不切换。

单场景中间视角的13场景几何平均结果同样约为1.22%，说明三视角汇总没有改变总体趋势。

## 6. 当前架构判断

1. 真实负载确认光栅化是主要瓶颈，支持R1将alpha和blend配对的结构选择。
2. 帧内动态切换存在少量潜在收益，但39视角平均约1.23%，尚不足以单独证明复杂可重构互连值得实现。
3. 当前更合理的主候选是“光栅优先R1＋低频粗粒度模式切换”，而不是频繁逐组重配置。
4. 若ASIC综合显示动态互连的面积、频率或功耗代价超过约1%至2%，应优先收敛为场景级/子图级配置。
5. 逐像素提前终止可能显著改变深层窗口的光栅负载，必须在最终决策前补充代表场景精确轨迹。

## 7. ASIC评价指标

后续B0/R1公平对照采用ASIC PPA指标：

- 工艺节点、标准单元库、SRAM编译器和PVT角必须一致。
- 面积报告区分组合逻辑、触发器、SRAM宏和时钟树估计。
- 时序报告至少包含目标频率、WNS/TNS、关键路径类型和流水启动间隔。
- 功耗区分动态、漏电、时钟网络、存储宏和片外IO估计。
- 能效报告使用能量/帧、能量/高斯和有效块任务/焦耳。
- 比较必须使用相同数值格式、存储容量、带宽上限和输出分辨率。

## 8. ASIC阶段门槛

### 8.1 动态R1保留门槛

只有同时满足下列条件，才保留帧内动态切换作为论文主方案：

1. 多视角真实负载在加入精确alpha/终止后仍有稳定收益。
2. 共享互连、配置控制和epoch排空的面积开销可接受。
3. 重构后目标频率不因多路选择和长ready路径明显下降。
4. PPA归一化后的能量或吞吐收益大于控制复杂度。

### 8.2 简化条件

- 若跨场景最佳模式不同但帧内变化小：采用场景级配置。
- 若所有场景仍由光栅优先占优：采用固定光栅优先R1。
- 若配对资源综合代价过高：退回B0，并保留提前终止、延迟SH读取和块跳过。
