# ADR-006：alpha采用保半正定Cholesky块浮点格式

- 日期：2026-08-04
- 状态：首个RTL候选已接受，待整图画质与PPA复核

## 决策

alpha二次型不再直接量化三个conic系数，而由投影阶段生成Cholesky因子。坐标与因子分别归一化并携带小型二进制指数；光栅阶段计算两项平方和，随后使用256项exp LUT和Q1.12 opacity得到alpha。

首版格式为：delta Q5.10，Cholesky Q3.12，轴中间量Q4.10，指数/opacity/alpha 12小数位，透射率Q0.16。

## 理由

- 统一Q格式在真实负载上的阈值分类不一致率为33.72%，不可接受。
- 单共享尺度仍要求因子较宽，并可能因独立conic量化破坏半正定性。
- 双指数块浮点避免宽整数乘法器；Cholesky结构保证量化后指数不会因负二次型错误增大。
- 90万真实样本上，首个面积均衡候选分类不一致约0.186%，P99误差约0.01044。

## 后果

- 投影输出事务增加三个Cholesky因子及两个有符号指数。
- 需要在整幅图像上继续评价误差积累、PSNR、SSIM和LPIPS。
- 256/512 LUT、因子位宽和轴位宽最终由具体节点PPA与整图画质共同裁决。
