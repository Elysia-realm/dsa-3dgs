# 稳定段逆序与末项二分发射

日期：2026-09-14。目标是修复上轮排序退化反例、降低无效检测工作，保持固定
`depth_group → ordered_gaussian_issue_retire → per_gaussian_8x8_block_walk`及动态G/P/R/E。
候选仍默认关闭，Gate 1/2仍PARTIAL；本轮不宣称最终加速器、最优排序或PPA完成。

## 1. 实现与正确性边界

`stable_group_sorter_parallel_shared`新增`ENABLE_STABLE_RUN_FASTPATH`，由frame/system的
`PARALLEL_SORT_STABLE_RUN_FASTPATH`传递；只有monotonic开关开启、比较lane数及首项
预算均>1时才生效。旧monotonic消融显式关闭该新开关，生产`USE_PARALLEL_GROUP_SORT=0`
不变；预算1的流式稳定插入、非单调组的奇偶网络、共享G/P竞争不变。

完整键顺序仍为signed depth / unsigned gid / unsigned seq，payload不是排序键。
非递增组按相等完整key段逆向遍历，段内保持到达顺序。每个保留记录仅保存一个
ADDR_W位run-start地址，增加遍历游标；不复制Gaussian key/payload数组。
地址元数据与读选择逻辑仍有实际面积/时序/功耗成本，没有综合/STA/功耗数据。

若仅保留的最后一项打破非递增前缀，共享G PE先比较tail与前缀最大键；tail不小于
最大键时直接排在最后，否则对物理非递增前缀二分寻找第一个key<=tail的位置，
换算成有序发射的插入slot。相等前缀记录先发射，后来接受的tail随后发射，保证稳定性。
没有按场景白名单选择算法，没有为末项添加专用全key比较器。

检测方向ascending/descending均失效后不再产生collect_compare_fire。复用的lane1
比较器只在接受保留记录且方向仍可能单调时计入local/collect工作。溢出丢弃尾项不改变
保留前缀结论；末项二分只能针对实际保留的最后一项，不能把丢弃记录当tail。

APB地址及12类快照协议不变：shared包含新增末项验证/二分比较；local包含collect；
reverse包含反向遍历稳定段及前缀+tail，不能理解为反转所有记录。计数仍是模32位区间
工作量，不是能耗实测。first/last与逻辑输出位置绑定，停顿时payload/标签/标志保持。

## 3. 四路整帧路径验证

同一3-Gaussian场景分别输入正序、逆序、逆序前缀+最大tail、逆序前缀+居中tail，
四帧各1,733commit、最终每个已覆盖pixel的RGB/T及覆盖集合逐bit一致。APB确认fast=1，
reverse分别0/1/1/1，collect均2，shared分别0/0/1/2。每帧fresh-start测量基线重建，
epoch清帧仍通过。这是commit-backed image-state测试，不是packed RGB DMA成品接口签核。

Icarus最终75自检+1次综合入口编译通过，`iverilog_final.log`包含四帧结果。默认及候选
生产顶层Verilator lint/展开通过，没有Error/LATCH/MULTIDRIVEN/UNOPTFLAT；仍有历史
非致命宽度/未用信号等告警，不能称lint零告警或SVA/门级通过。
