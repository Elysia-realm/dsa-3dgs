# SH颜色与64像素展开规格 v0.1

- 日期：2026-08-09
- 路线：GCC式深度分组、Gaussian有序发射、Gaussian内部8×8 block遍历
- 边界：不建立Gaussian–tile KV/bin，不进行逐tile排序

## 1. 设计位置

每个Gaussian在进入自身的block遍历前只计算一次SH颜色。该RGB结果随Gaussian描述符保存，并在该Gaussian覆盖的所有block和pixel之间复用。逐像素路径只计算坐标差、alpha、blend和终止状态，不重复读取48个SH系数，也不重复进行SH MAC。

动态可重构模式可在epoch安全边界改变SH/光栅物理lane的启用数量；固定基线与动态模式共享同一组定点格式、SH基函数顺序和舍入规则，因此模式切换不得改变数值结果或Gaussian深度顺序。

## 2. 真实负载范围与定点格式

`scripts/profile_sh_fixed_format.py`只读取本地`data`目录的13个场景，每场景最多抽样100000个Gaussian，并把结果写入本地`experiments/sh_fixed_format_profile.json`。

观测范围：

- SH系数绝对值最大约7.79183；
- degree-3基函数绝对值最大约0.74635；
- 加0.5但裁剪前的颜色范围约-0.529至3.087；
- 每Gaussian为RGB三通道、每通道16项，共48个系数。

首版冻结格式：

| 对象 | 格式 | 说明 |
|---|---|---|
| 世界坐标/相机位置 | signed Q10.16，27位 | 相减时先扩宽一位 |
| 归一化方向 | signed Q1.20，22位 | 零向量回退到(0,0,1) |
| SH系数 | signed Q5.12，18位 | channel-major：R0..15、G0..15、B0..15 |
| SH基函数 | signed Q11.20，32位 | 与参考模型顺序严格一致 |
| 颜色MAC | signed 64位，Q32 | 16项宽累加后统一舍入 |
| RGB输出 | unsigned Q1.12，13位 | 加0.5后裁剪至0..4096 |

SH常数使用Q20编码。基函数定义与`model/reference/math3d.py`一致，不允许交换符号或系数次序。

## 3. RTL模块

- `rtl/sh/view_direction_normalizer.sv`：平方和、整数平方根、三轴除法和零向量回退；支持ready/valid全局背压。
- `rtl/sh/sh_degree3_color_core.sv`：16项degree-3实SH基函数、三通道宽MAC、0.5偏置及饱和裁剪。
- `rtl/sh/gaussian_sh_color_core.sv`：世界均值减相机位置、方向归一化与颜色计算封装；fallback和overflow与最终输出事务对齐。
- `rtl/raster/gaussian_block_pixel_expander.sv`：把当前Gaussian的一个8×8 block展开为逐拍pixel事务；同时应用bbox和整图边界mask。
- `rtl/raster/ordered_block_raster_frontend.sv`：接收已经按Gaussian顺序退休的block，将缓存的RGB和alpha描述符送入现有termination/alpha/blend链。

## 4. 像素展开合同

- block原点为`(block_x*8, block_y*8)`；
- 输出顺序为block内row-major；
- 仅输出满足图像边界与半开bbox`[x0,x1)×[y0,y1)`的像素；
- `pixel_in_block={local_y,local_x}`，范围0..63；
- `pixel_id=pixel_y*image_width+pixel_x`，完整链使用32位线性地址，不再受原12位/4096像素限制；
- `dx/dy=round((pixel-mean)/2^coordinate_shift*2^10)`，饱和到signed 16位；
- 空block或culled事件在输入握手时被消费并产生退休脉冲，不产生伪pixel；
- 输出背压期间，所有事务字段保持稳定。

## 5. 当前已验证内容与未闭环边界

五个新增自检查testbench覆盖方向解析点、零向量、SH符号/裁剪、metadata保序、bbox/图像裁剪、row-major遍历、32位线性地址、空block/cull、背压以及单像素贯通alpha/blend。

当前尚未把排序后的完整Gaussian属性、projection结果和SH结果统一fork/join到系统级`gs_accel_top`。因此本规格证明的是新增子链可编译、接口与算术合同成立，不表示完整加速器、完整帧RTL或ASIC PPA已经完成。
