# RTL验证日志：共享PE首次接入生产G/P数据流

日期：2026-09-12

## 1. 目标与不变量

本轮继续Gate 1，把上一轮独立共享compare/MAC切片接入唯一生产路径，同时保持：

```text
深度分组 → Gaussian有序发射/退休 → Gaussian内部8×8 block遍历
```

没有新增per-tile bin/list/sort，没有改变覆盖集合、像素顺序或framebuffer格式。

## 2. 生产接入

- 新增`gaussian_depth_prepass_shared_mac.sv`，将相机空间Z点积串行为三次P客户端全精度MAC，
  保留Q20舍入、饱和、near/far可见性、sequence和ready/valid合同。
- 新增`stable_group_sorter_shared_compare.sv`，将稳定插入排序的
  `(signed depth,unsigned gid,unsigned sequence)`比较全部交给G客户端，存储和发射顺序不变。
- `gaussian_frame_render_pipeline`默认`USE_SHARED_PE=1`，只实例化一个
  `shared_reconfigurable_pe_slice`；0值分支保留旧prepass/sorter作为差分golden。
- mode table的G/P/R weight、shared owner、aggressive gate及`mode_commit_pulse`已接入共享切片。
- 帧级输出grant/stall/utilization/busy/clock-enable；系统顶层提供饱和累计计数。
- APB新增只读寄存器：`0x064/068/06c`为G/P/R grant，`0x070/074/078`为G/P/R stall，
  `0x07c`为共享PE utilization。
- 系统顶层新增`USE_SHARED_PE`参数，使同一DMA测试平台可直接执行生产/旁路A/B。

## 3. 定向验证

`tb_gaussian_depth_prepass_shared_mac`将旧/新两条prepass并行对拍，覆盖单位旋转、非平凡旋转、
平移、负值及溢出边界，4/4结果逐bit一致。

`tb_stable_group_sorter_shared_compare`将旧/新排序器并行对拍，覆盖两个group、相等深度、GID及
sequence稳定决胜和随机下游反压，7/7发射逐bit一致且G grant非零。

帧级测试确认4个Gaussian产生12次P grant且G grant非零；系统顶层测试通过APB确认1个
Gaussian产生3次P grant、0次R grant以及匹配的utilization。

## 4. 真实DMA A/B

同一4-Gaussian微负载结果如下：

| 路径 | cycles | commits | state reads | state writes |
|---|---:|---:|---:|---:|
| `USE_SHARED_PE=0`旁路golden | 602 | 68 | 68 | 68 |
| `USE_SHARED_PE=1`生产共享路径 | 627 | 68 | 68 | 68 |

共享路径增加25 cycles，即`25/602=4.152824%`。输出提交数和AXI状态流量完全相同，说明功能
等价成立；但当前串行MAC/compare握手增加了前端延迟，不能宣称性能提升。该开销被写入机器
可读状态并成为后续优化必须消除的基线。

## 5. 回归

- Python unittest：113/113 PASS；
- Icarus Verilog：68项SystemVerilog自检及1次综合入口PASS，其中包含共享/旁路DMA A/B；
- Verilator 5.050：`gs_accel_system_top`生产顶层lint PASS；
- 新共享排序适配器独立lint无Warning/Error；顶层仍保留既有非致命width/unused告警。

## 6. 状态与下一步

Gate 1仍为PARTIAL。已经成立的是：两个生产客户端确实复用同一算术实例，mode table和epoch
控制真实生效，结果及活动可观测。尚未成立的是：

1. P客户端只是collect阶段的相机Z预处理，尚未替换主投影阵列MAC；
2. R客户端未接入；
3. 当前G/P阶段不重叠，没有生产仲裁竞争，weight尚不能形成吞吐差异；
4. 尚无面积、频率或功耗收益，微负载反而有4.152824%周期开销。

下一轮应将主投影内一个可停顿MAC接入P客户端，使其与后续group的G比较发生真实重叠，再接入
一个无状态R算子。继续保留bypass逐bit对拍；如果单切片串行化无法消除开销，则扩展为可参数化
多slice阵列并做吞吐/面积折中，而不改变Gaussian-wise主路径。
