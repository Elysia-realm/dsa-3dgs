# ADR-005：冻结完整RTL、三项画质指标与具体节点PPA为强制交付

- 日期：2026-08-04
- 状态：已接受

## 背景

用户明确毕业设计需要提交完整RTL代码，使用SystemVerilog，图像质量评价必须包含PSNR、SSIM和LPIPS，并最终给出具体工艺节点下的面积与功耗。当前只有控制/终止相关RTL骨架和软件模型，ASIC工具与工艺库尚未准备。

## 决策

1. 正式RTL语言冻结为SystemVerilog；现有关键模块不能作为最终完整交付的替代品。
2. 建立端到端模块清单和可验收状态，最终必须覆盖控制、DMA、存储、投影、排序、SH、任务、alpha、blend、图像状态、终止、scoreboard、动态模式和计数器。
3. 图像质量同时建立PSNR、SSIM、LPIPS入口。PSNR/SSIM可使用当前本地运行时；LPIPS只在本地离线依赖和权重准备好后运行，不联网下载。
4. 面积与功耗结果只在明确工艺节点、库、SRAM宏、PVT、频率和活动条件后报告。工艺无关阶段不得将抽象资源额度称为面积。
5. 在具体节点未冻结前，所有大容量存储通过可替换wrapper设计，避免逻辑数组结构阻碍后续SRAM宏映射。

## 后果

- 工作量从关键模块原型扩展为完整SoC侧加速器数据通路，必须按模块分阶段验收。
- 画质实验不能只给PSNR，且必须说明参考对象是FP32渲染还是数据集GT。
- PPA会成为架构是否保留动态重构逻辑的最终裁决依据，而不是附加展示项。
- 当前可以继续完整RTL接口、数值模型和真实负载验证；具体PPA暂时是有明确定义的外部依赖，而非当前可产出的数字。
