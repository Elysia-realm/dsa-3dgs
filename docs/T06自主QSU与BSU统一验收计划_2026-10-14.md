# T06 自主 QSU 与 BSU 统一验收计划

状态：开发中，未签核。日期：2026-10-14。

2026-10-22补充：本文件原计划与历史状态保留；T06已按当前发布配置完成功能签核，
见docs/T06功能签核与性能交接_2026-10-22.md。按用户10-18后续场景政策，本轮使用
Bonsai/Counter/Room/Train/Truck（相机146/120/155/150/125），Kitchen/Garden保留历史
证据并暂缓新增测试，T00最终范围不变。真实子集统一128宽，完整模型同宽低分辨率仅验
自主调度及图像语义；正式目标分辨率/GT/30FPS不在本次通过范围。

## 冻结责任与架构

保持 T05 K16 空间流水、双输入缓冲、真实共享 G/P/R 和 Gaussian-wise 主路径。
CPU 仅解析/编码模型与相机、分配暂存地址；不得生成硬件测试的排序、pivot 或容量安全批次。
单命令接收无序完整输入，硬件完成深度预遍历、可见描述符暂存、全局分组和有序发射。

首选 7 pivot / 8 子集。硬件用每个节点的 min/max 完整 key 找到最高不同位，生成
对齐的八路范围边界，七个比较并行得到桶号。对子集计数、前缀 offset、稳定 scatter；
超过 K 的子集继续在片外 ping-pong 区间内划分，按深度优先的近到远顺序处理。
key 为有符号深度（翻转符号位后比较）、无符号 GID、无符号 sequence。相同深度继续
按 GID/sequence 分裂；完全相同 key 保持稳定到达序，可按 K 顺序切分而不破坏全序。
栈按 key 位宽给出有限上界，不能按场景 Gaussian 数量分配片上数组。

读取和写入均使用正式、可回压的 DMA；父节点全部写响应退休后才读子节点。
叶子读取可与先前叶子的 BSU 和渲染并行；不得对每个 K 子集重启相机、epoch、RGB DMA。
保留旧 3-pivot 命令为兼容/消融，不作为自主能力证据。

## 必需验收（开始测试前确定）

1. 模块全 key 精确对拍：空、1、15/16/17、非二次幂、多组、正逆序、随机、重复深度、
   相同 GID/key、极端倾斜、跨符号边界；背压下输出稳定、不重不漏；有限递归终止。
2. 实际 QSU+T05 BSU 联合对拍，记录叶子填充、共享 G 活动、收组/排序/发组重叠、
   周期、读写字节及 stall。用同一输入与折叠 BSU 作一次对照，不承诺全场景最优。
3. DMA 地址对齐/边界/容量检查，读写错误、完成/IRQ/事务排空、重复帧和相机改变；
   不允许错误后继续宣称成功图像。输入数与 sequence 不得在完整模型范围内溢出。
4. 完整模型容量与全局排序：至少 Bonsai、Counter、Room、Kitchen、Garden 的
   iteration_30000 全 Gaussian；固定相机沿用 146/120/155/139/92。报告完整数量、
   可见数量、源码/输入哈希、软件 oracle 与实际执行层级；模块级不能冒称生产顶层通过。
5. 五场景生产顶层新增路径开启，以原始无序模型编码输入经过相机/mean/attribute DMA、
   自主 QSU、K16 BSU、渲染、RGB DMA。先用每场景 512 条/长边64的调试子集闭环，再
   扩至完整集合的低分辨率验收；低分辨率仅验自主调度与输出一致性，目标分辨率/GT归T10。
   G/P/R/E、ideal/limited AXI 的五场景子集矩阵至少40次；完整集合至少五场景G模式。
6. 图像只能封装 AXI RGB 字节，核对 DMA 转储/PNG，查看实际成品并记录异常。
   与独立全局排序 oracle 驱动的旧路径作字节比较；软件排序只出现在 oracle 中。
7. 当前源集成回归、lint、可综合性及新增片上存储/逻辑资源说明。全芯片PPA不在本次签核。

只有上述必需证据逐项闭环才可签核；否则保留开发中/验收进行中。完整场景测试成本不是
自动缩小范围的理由。可选优化小于约1%且不影响硬线时停止，正确性和必要验证除外。

## 文献依据与差异

本地 `参考文献/GSCore.pdf` 第7页§4.2/图7、第8–9页§5.3及图10/11：近远有序粗分组、
7-pivot QSU、计数/offset、容量内16路BSU、精排与渲染重叠。论文按tile分组并利用tile
提前终止；本项目禁止改为tile binning，保持Gaussian-wise全局顺序。论文没有提供本项目
重复key、有限存储、AXI错误恢复所需的完整协议；本实现用硬件范围边界与稳定scatter补齐，
不照搬随机pivot或宣称达到论文性能。本轮只实现一个有界主方案并测量，不扫描更多pivot数。
