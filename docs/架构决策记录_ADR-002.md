# ADR-002：ASIC主候选采用光栅优先R1并限制帧内动态复杂度

- 状态：暂时接受，等待精确alpha轨迹和ASIC PPA复核
- 日期：2026-08-04

## 背景

R1合成实验表明配对alpha/blend资源可消除R0的固定blend瓶颈。现在已对13个真实场景、39个抽样视角完成候选块级负载分析。

## 观察

- 39个视角的最佳固定配置全部为光栅优先。
- 动态模式相对最佳固定模式的候选周期几何平均收益约1.23%。
- 11个视角超过1%，9个超过2%，最大约7.71%。
- 5个视角完全不切换。
- 当前分析未包含精确alpha、提前终止、SRAM冲突和ASIC互连成本。

## 决策

将“光栅优先R1”设为ASIC实现主候选，保留低频粗粒度配置能力，但暂不投入复杂的逐组动态互连和在线调度器。

## 理由

1. 真实负载一致显示候选块处理是主瓶颈。
2. 平均动态收益偏小，可能被ASIC面积、频率和功耗代价抵消。
3. 保留shadow/active配置和epoch边界控制，可在后续证据充分时升级为动态方案。
4. 先实现固定光栅优先数据通路，更容易获得可信的PPA基线。

## 后果

- RTL先实现通用流接口、配置提交、性能计数器和配对光栅通道。
- 投影/排序配置能力保留在参数与控制接口中，不立即实现大规模可切换PE互连。
- 论文可以将动态模式作为设计空间探索和消融项，而不是预设必须成功的主结论。

## 复核条件

1. 精确提前终止轨迹使深层窗口负载显著下降并形成稳定模式变化。
2. ASIC综合显示共享互连与配置控制开销很低。
3. 更多相机或不同数据集显示动态收益显著高于当前约1.23%。
4. 场景级最佳模式不再全部为光栅优先。
