# 3DGS动态可重构ASIC加速系统规格 v0.6

- 日期：2026-08-04
- 状态：工艺无关RTL控制骨架和代表场景精确ROI轨迹完成
- 目标平台：ASIC
- 继承：`系统规格_v0.5.md`的光栅优先R1、epoch协议和ASIC评价边界
- 保密要求：真实模型、轨迹和实现仅保存在`D:\3DGS`本地

## 1. 本版结论

主候选维持“光栅优先R1 + 低频粗粒度配置能力”，但优化重点进一步明确为：

1. 优先实现逐像素透射率、块终止掩码和跨阶段跳过，使深层高斯不进入alpha流水或属性读取。
2. 保留shadow/active配置和epoch边界，暂不实现复杂逐窗口动态互连。
3. 配对光栅通道必须在任意背压下保持task/block/gid/epoch标签，且每个接受任务恰好提交一次。
4. 只有目标库综合证明动态配置存在PPA净收益，才提升其为论文主加速机制。

## 2. 工艺无关RTL控制基线

已实现以下可综合SystemVerilog模块：

- 单项ready/valid弹性寄存切片；
- 两项skid buffer，用于切断长ready组合路径；
- shadow/active配置控制器，只在`epoch_boundary && affected_empty`时原子提交；
- epoch ID递增和重复commit sticky告警；
- 可清零、可快照的64位饱和性能计数器组；
- 配对alpha/blend光栅通道控制壳，包含多级弹性流水和两项结果队列。

当前光栅通道只冻结事务协议，尚未接入定点alpha/exp、颜色累积、T更新和真实scoreboard存储。

## 3. 接口不变量

1. 事务仅在`valid && ready`时发生。
2. `valid && !ready`期间payload保持稳定。
3. 输出提交数不得超过输入接受数；排空后两者必须相等。
4. 配置变更仅允许在受影响流水、结果队列和scoreboard均安全排空的epoch边界发生。
5. 同周期shadow写入与安全commit时，active获取本次写入的新值。
6. 所有计数器饱和而不回绕；snapshot读取同一时点的旧计数值。

## 4. 代表场景精确ROI轨迹

方法：对完整iteration 30000高斯集合执行真实相机投影，将最长边缩放到960；在中心64×64 ROI内按深度和GID稳定次序执行逐像素alpha、前向blend和T终止。该实验是精确ROI语义，不是全帧性能结论。

| 场景/视角 | ROI高斯 | 候选块 | 终止后活跃块比 | alpha计算比 | blend比 |
|---|---:|---:|---:|---:|---:|
| garden / 184 | 38,866 | 167,828 | 28.69% | 38.47% | 35.78% |
| train / 150 | 46,532 | 250,986 | 2.70% | 4.67% | 8.12% |
| bonsai / 291 | 15,081 | 164,729 | 7.64% | 9.98% | 12.54% |

三个ROI的4096个像素最终均达到`T < 1e-4`。结果表明，候选包围盒任务数显著高估深层实际光栅工作；提前终止在样本ROI中减少61.5%至95.3%的alpha计算。它不会直接证明动态资源配置无收益，但会重塑窗口级负载，因此必须用终止后的任务流重新评估R1模式选择。

## 5. 更新后的数据流要求

1. 投影阶段生成屏幕包围盒和块列表。
2. 深度有序任务进入块状态查询；已终止块在读取SH/颜色和进入alpha阵列前丢弃。
3. alpha结果通过有限队列进入同块有序blend提交。
4. blend更新T后生成像素终止位；块内像素全部终止后写入块终止标记。
5. 终止掩码应驻留片上并按块bank化；读查询与blend写回应定义冲突优先级。
6. 计数器至少覆盖候选块、终止块跳过、alpha计算、alpha裁剪、blend更新、队列满、scoreboard等待和epoch排空。

## 6. 验证状态与工具边界

软件自动化测试现为45项，覆盖黄金渲染、周期模型、真实数据导入和RTL协议行为。RTL文件包含关键SVA，但本机当前未发现Icarus Verilog、Verilator、Yosys或商业ASIC工具，因此尚未完成真实RTL编译、仿真、lint、形式验证、综合、STA和功耗分析。

获得ASIC工具链后必须按下列顺序补齐：

1. 编译与lint；
2. 随机背压仿真和SVA；
3. 配置原子性形式验证；
4. 在同一标准单元库和SRAM宏下综合B0与R1；
5. STA报告WNS/TNS及关键路径；
6. 门级或RTL活动率驱动功耗估计。
