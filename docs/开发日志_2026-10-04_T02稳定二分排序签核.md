## 2. 实现与比较方法

- `stable_group_sorter_shared_compare` 增加 `ENABLE_BINARY_SEARCH`，默认 0。
- `gs_accel_system_top` → `gaussian_frame_render_pipeline` 贯通 `SHARED_SORT_BINARY_SEARCH`，默认 0；只作用于共享串行排序分支。既有并行排序候选及其逆序前缀末项二分保持原实现。
- 对已排序区间 `[lo, hi)` 进行 upper_bound 定位。既有 G 比较器判断新键是否严格小于中点键；相等完整 `(depth, gid, sequence)` 进入右半区，新记录排在已有相等记录之后。
- 保留寄存器数组、插入搬移、有序发射和粘滞溢出行为。下一比较可以在返回当前结果时发出；被仲裁阻塞时保存新区间和索引，保持请求稳定。
- 预先冻结的范围与停止条件见 `experiments/t02_20261003/plan.md`。本次只有一个优化方案。

下表统计二分候选相对共享线性基线的周期减少百分比；平均值为各模式/AXI 配置百分比的算术平均。

| 固定负载 | 输出分辨率 | 提速 / 持平 / 退化 | 平均节省周期 |

| Train n128 d8 | 8×4 | 8 / 0 / 0 | 9.977% |
| Train n128 d64 | 64×36 | 8 / 0 / 0 | 1.840% |
| Garden n32 d64 | 64×41 | 8 / 0 / 0 | 0.287% |
| Kitchen n32 d64 | 64×43 | 1 / 4 / 3 | 0.006% |
| 合计 | — | 25 / 4 / 3 | 3.027% |

稀疏 Train G/ideal：4721 → 4130 周期，减少 591 周期（12.519%），但旁路为 3275 周期，仍不能宣称共享方案已全面胜过旁路。所有结果只覆盖上述真实场景抽样负载的完整 RGB/T 状态输出，不代表全 Gaussian 场景、最终 RGB DMA、1080p、GT 画质或 30 FPS 签核。

Kitchen 三项退化均为增加 1 周期；最差比例约 0.0534%。该幅度不足以支持继续多轮修补，且未满足预先要求的系统样本无退化门槛。因此保留反例，维持生产默认关闭，结束 T02。
