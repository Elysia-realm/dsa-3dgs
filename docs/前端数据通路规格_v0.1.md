# 3DGS前端数据通路规格 v0.1

- 日期：2026-08-04
- 目标：为动态可重构ASIC加速器提供可复制的投影lane，直接输出深度排序所需
  depth、Gaussian描述符和8×8 tile任务；不依赖软件预投影。
- 状态：首个工艺无关定点RTL候选及Icarus自检查仿真完成。

## 1. 设计目标护栏

1. 前端只实现3DGS所需的世界/相机变换、透视均值、屏幕协方差、保守包围盒和
   Gaussian–tile任务生成，不扩展为无关的通用图形流水。
2. 投影lane使用ready/valid并可复制。动态模式仅在epoch安全边界改变启用lane
   数量；固定基线和动态方案共享相同算术与任务描述符。
3. 输出保留完整Gaussian元数据、Q10.16深度、Q18.8屏幕均值、Q24.8二维
   协方差、裁剪后bbox和tile坐标，后续排序、conic/Cholesky编码与SH可直接消费。
4. 数值溢出不得造成错误剔除。均值/协方差异常时采用保守全屏bbox并设置标志，
   以额外工作量换取不漏渲染；near/far和完全不相交屏幕仍可正常剔除。

## 2. 真实场景范围依据

从本地13个iteration 30000场景中，每场景读取首批20000个Gaussian，并选择首、
中、末3个相机，统一缩放到最长边1920进行范围审计：

- 780000个world坐标绝对值样本最大约55.56。
- 2101335个camera坐标绝对值样本最大约51.67。
- 700445个可见深度样本范围约0.20至51.67。
- 屏幕均值绝对值P99约8895，最大约173384像素。
- 二维协方差绝对值P99约147921，极端最大约1.13×10^10。
- FP32精确半径P99约1760，极端最大约293348像素。

因此不能按“均值一定在屏幕附近”假设分配位宽，也不能在溢出时直接丢弃。

## 3. 首版定点合同

| 数据 | 格式 | 说明 |
|---|---|---|
| 世界/相机坐标、translation、depth | signed Q10.16，27位 | 覆盖约±1024 |
| view rotation | signed Q2.20，22位 | 支持量化旋转矩阵 |
| fx/fy/cx/cy | signed Q16.16，33位 | 覆盖高分辨率相机内参 |
| 屏幕均值 | signed Q18.8，27位 | 覆盖约±262144像素 |
| 3D协方差 | signed Q24.16，41位 | 相机空间对称矩阵6项 |
| 2D协方差 | Q24.8，32位 | diagonal无符号、off-diagonal有符号 |
| bbox像素坐标 | unsigned 16位 | 半开区间[x0,x1)、[y0,y1) |
| tile坐标 | unsigned 12位 | 当前tile尺寸8×8 |

## 4. RTL模块

- `fixed_div_pipe2`：双路共享正分母、全流水恢复除法器；每级求1位，吞吐1组/周期，
  完整支持ready/valid背压、符号、除零和饱和标志。
- `world_to_camera_core`：3×3旋转加translation，乘加后舍入饱和。
- `perspective_project_core`：计算fx*x/z+cx、fy*y/z+cy并执行near/far判断。
- `screen_covariance_core`：计算Jacobian和JΣJᵀ，加0.3正则化；两组除法流水
  计算1/z和1/z²相关项。
- `bbox_tile_bounds_core`：用Gershgorin上界保守估计最大特征值，首版生成3σ
  包围盒并裁剪到屏幕；异常时生成全屏范围。
- `gaussian_tile_task_gen`：按row-major顺序无遗漏/无重复枚举inclusive tile矩形，
  背压时保持描述符与坐标。
- `camera_projection_tile_lane`：均值和协方差路径原子fork/rejoin后生成tile任务，
  是未来动态改变投影lane数量的最小复制单元。

## 5. 当前限制和下一步

- 当前lane输入是相机空间3D均值与相机空间3D协方差。世界空间Gaussian的
  quaternion/scale到Σ3D以及Σ3D的view旋转仍需补充RTL。
- 当前bbox固定3σ，保证保守但会比FP32黄金模型基于opacity/alpha阈值的半径更大。
  下一版加入opacity半径LUT，在不缩小于黄金支持域的前提下降低任务数。
- 当前二维协方差尚未在RTL中完成逆矩阵和Cholesky块浮点编码；这是把前端描述符
  直接接入现有`alpha_block_float_core`之前的关键缺口。
- 当前projection lane尚未连接`gs_accel_top`、排序队列和动态lane仲裁器；因此
  本轮属于前端子系统RTL，不声称完整端到端加速器已闭环。
