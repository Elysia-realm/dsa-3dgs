# T06共享点积并行候选

状态：实现/验证中，默认关闭，不代表达到30FPS或通过STA。

## 为什么需要结构变化

F完整模型计数显示，单独P服务次数就是200MHz/30FPS预算的1.71–3.39倍；Truck深度预遍历
的3N次MAC也已超过总帧预算。即使R完全消失，单MAC串行P仍无法达标，故不能继续只调队列。
本地GCC第7页§4.2–4.3的并行MVM与交错流水是依据，但其规模/精度/时序不能直接套用。

## 唯一候选D

新增可关闭SHARED_P_DOT3：P请求携带三个独立signed32操作数对，一次完成
sum(x_i*r_i)+acc；深度预遍历3次请求变1次，XYZ变换9次变3次。
使用96bit packed操作数通路，结果仍为原65bit累加精度，保持原舍入/饱和/可见性。
原共享乘法器继续承担G/P/R的首项；P额外使用两个乘法器和加法树。
G稳定比较、R的old_t*alpha、权重仲裁、弹性结果保持与epoch排空不取消。
专用新增资源须单列，不宣称所有乘法器均跨G/P/R复用。

纯组合点积可能增加时序路径；本阶段只验证功能/周期及结构，未获得目标工艺STA前不提升默认。
不把3倍算术请求缩减称为3倍整帧加速。属性带宽、QSU访问、合成仍是独立约束。

## 测试前冻结的验收

1. signed dot3与逐项65bit模加独立对拍，正负/边界/溢出、仲裁竞争和响应背压。
2. 深度及XYZ的round/saturate/overflow与原标量和本地参考逐项一致；G/R行为不退化。
3. 五真实场景、四模式、两AXI，共40次D，与冻结A逐字节RGB/全序对拍；预遍历和XYZ
   实际P授权数分别由3N/9V缩为N/3V，证明生产顶层走新通路。
4. 正确且有收益后才做完整模型验证、当前默认/命令/相机/RGB/异常/epoch回归和PPA评估。
   任何缺项都不得签核。A完整模型另从已冻结快照运行，不受本次源码变动影响。
