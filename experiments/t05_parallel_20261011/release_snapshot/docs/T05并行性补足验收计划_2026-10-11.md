# T05 并行性补足：测试前冻结计划

状态：2026-10-12完成技术验证，2026-10-13完成证据归档及重新签核。旧折叠实现与证据完整保留在2026-10-09实验目录，本轮新证据使用
`experiments/t05_parallel_20261011`。目标是实质增加运算并行和阶段重叠，不靠扩大用例数签核。

## 架构与文献依据

前轮已核实本地GSCore PDF第9页§5.3、图10/11，以及第11页§7.3、图14：其收益来自
QSU小子集、BSU并行精排、排序与光栅重叠和提前终止共同作用；第12页§7.5明确讨论
大块与小块的权衡，不能只给16通道喂8项就冻结选择。保持本项目Gaussian-wise路径，
不改成tile binning；T06负责硬件pivot/容量管理，本轮只建立可连续接收有序子集的接口。

实现K8/K16空间展开、逐层寄存的Bitonic网络（24/80个逻辑CAS）。第一层首对保留真实
G共享比较，其他CAS专用并行执行；这比每一折叠批都等待G握手更少串行依赖，同时保留
G/P/R真实共享目标。采用双输入组缓冲、弹性层间寄存器与输出串化，允许收组、多个网络
阶段、发组重叠。G请求必须先预留响应空间，防止G持有共享PE结果又等待下游P/R的循环阻塞。

专用BSU每个有效阶段保持全并行；G/P/R/E继续通过共享PE信用/权重、输入服务和P/SH/alpha
lane配置改变实际服务，不能再把E模式强制改为逐对遍历整张网络。按有效token更新寄存器，
无任务的阶段不更新数据。明确此专用网络与共享MAC的边界，不夸称所有算子动态共用。

## 必须完成的比较与验证

1. K8/K16、折叠/空间流水四种BSU：同位宽、同K输入，完整稳定key及到达序号，空/非满/满、
   随机/正逆序/重复、输入输出及PE背压、连续组、溢出恢复；与独立软件排序逐项比较。
2. 连续满组理想条件：测首次延迟与稳态组间隔。空间流水目标稳态不超过K+1拍/满组；
   实测收发同时发生、多个排序阶段同时有效。另测带P/R竞争及长输出背压，禁止死锁/丢失。
3. 四种BSU均取得Nangate45/ICsprout55 TT模块映射，保存真实网表、面积、ABC组合估计。
   比较增加的寄存器/互连成本；不把ABC估计或模块面积当成全芯片STA/活动功耗。
4. 至少五场景，每场景固定512真实Gaussian、64像素长边，正式DMA输入到RGB输出。
   两个系统比较口径同时保留：共同8项组（隔离结构差异），自然容量K8/K16满组（比较容量收益）。
   同一K下每命令尽量包含4个有序子集，每子集内置乱；允许比较排序/渲染和相邻子集的重叠。
   CPU临时定义有序范围和pivot，输入/预处理成本明确，不计为T06自主能力。
5. 空间生产候选与折叠同K对照覆盖G/P/R/E、ideal/limited AXI；各自然容量路径RGB与稳定
   全局key顺序一致，记录序号的批次局部差异，不能将其误判为排序变化。必要时保留旧插入对照。
6. 用实际计数证明新网络执行及重叠；连续帧/模式切换/最终输出完成及错误恢复回归；映射、
   输入、源码与成品字节哈希齐全。检查实际PNG，明确子集画质范围。

根据自然容量与连续组吞吐、面积/时序风险选择生产参数，不预先认定K8或K16获胜。
功能与上述证据齐全后再签核。低收益规则只用于满足目标后的可选微调，不能跳过本轮架构比较。
